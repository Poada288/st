Для добавления нового терминала:
1) заходим в файл terminalsData.js
2) справа сверху нажимем кнопку-иконку "Карандаш", которая правее слова Raw
3) Листаем в самый низ
4) и перед квадратной скобкой добавляем: 

  {
    vendor: 'Вендор',
    model: 'Модель',
    connection_type: 'Тип подключения',
    terminal_type: 'Тип терминала',
    pinpad: 'да',
    sbp: 'да',
    preauth: 'да',
    no_cash: 'нет',
    qr_on_pinpad: 'нет',
  },
  
  5) заменяем информацию в нужных полях
  в полях pinpad, sbp, preauth, no_cash, qr_on_pinpad - ставим только да или нет, другие значени не принимает.
